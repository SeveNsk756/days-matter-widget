# 纪念日摆件

一个常驻桌面的纪念日倒计时小摆件，Days Matter 风格：透明无边框卡片，压在桌面角落，显示某个日子还剩多少天 / 已经过去多少天。

## 安装（普通用户）

下载发行版里的安装包，双击安装即可，装完桌面会有快捷方式，开始菜单里也能找到。

- **安装版**：`纪念日摆件-1.0.0-安装包.exe`，可以选安装目录，带卸载程序
- **便携版**：`纪念日摆件-1.0.0-便携版.exe`，双击直接跑，不写注册表、不留痕

**系统要求**：Windows 10（1809 及以上）/ Windows 11，64 位。Windows 7 / 8 / 8.1 用不了——Electron 31 本身已不再支持这几个系统。

**安装包里不含任何个人数据**：你加的纪念日、位置、主题、节假日缓存都写在 `%APPDATA%\DaysMatterWidget`，发行版里只有程序本身。卸载时不会删这些数据，重新装回来还在。

**兼容性**：缩放 100% / 125% / 150% / 200% 都正常；多显示器、任务栏在上下左右都能正确摆放；窗口按钮是自绘的，不依赖系统标题栏样式，Win10 各版本表现一致。

## 从源码运行

```bash
git clone https://github.com/SeveNsk756/days-matter-widget.git
cd days-matter-widget
npm install             # electron、lunar-javascript、electron-builder
npm run prepare-assets  # 生成图标 + 把农历库复制到 renderer/lib/lunar.js
npm start
```

`prepare-assets` 做两件事：用 `make-icon.ps1`（GDI+，不依赖 Pillow）画出 `assets/icon.png` / `icon.ico`，以及把 npm 包里的 `lunar-javascript` 复制成 `renderer/lib/lunar.js`。仓库里不存这两个生成物，克隆下来跑一次就有了。

打包：`npm run build`，安装包和便携版都输出到 `dist/`。

## 怎么打开

开发态下，桌面上有 **「纪念日摆件」** 快捷方式，双击即可。

（快捷方式指向本目录下的 `node_modules\electron\dist\electron.exe`，所以**请不要移动或重命名这个文件夹**。如果换了位置，重新创建快捷方式即可：目标填 `electron.exe`，参数填项目目录。）

装好发行版之后，直接从开始菜单 / 桌面快捷方式启动就行。

## 怎么用

| 操作 | 效果 |
| --- | --- |
| 按住卡片拖动 | 移动摆件位置（自动记住） |
| 右键卡片 | 切换纪念日、换主题、置顶、锁定、开机自启、改尺寸、退出 |
| 卡片右上角 `‹ ›` | 上一个 / 下一个纪念日（鼠标移上去才显示） |
| 卡片右上角齿轮 | 打开设置 |
| Ctrl + 滚轮 | 切换纪念日（按「距离今天由近到远」的顺序走） |
| 双击数字 | 切换「今天算不算一天」 |
| 托盘图标单击 | 显示 / 隐藏摆件 |

关闭窗口（Alt+F4）只是隐藏，右键菜单或托盘里选 **退出** 才会真正退出。

**切换顺序**：所有条目（自定义纪念日 + 法定节假日）会按「距离今天还有几天」由近到远排成一圈，滚轮、`‹ ›` 按钮、右键菜单里都是这个顺序；已经过去的日子排在最后。距离一样时按你添加的先后排。跨天之后顺序会自动重排。

## 设置里能改什么

- 纪念日清单：名称、日期、颜色（可以随便加多少个，摆件上按顺序切换）
- **重复规则**：不重复 / 每年 / 每月 / 每周
- **生日**：勾上后自动按每年重复，卡片会显示「满 N 岁」
- 法定节假日：一键开关，自动算好 7 个中国法定节日，和自定义纪念日一起切换
- 深色 / 浅色主题
- 尺寸：小 / 中 / 大 / 特大
- 始终置顶、锁定位置、把今天也算一天、显示日期小字、开机自动启动

## 重复与生日（对标 Days Matter）

添加或编辑纪念日时，可以给事件选一个**重复规则**：

| 重复 | 摆件上数的是哪一天 |
| --- | --- |
| 不重复 | 就是你填的那一天；过了之后显示「已经过去 N 天」 |
| 每年 | 今年的那个月日；今年已经过了就自动滚到明年 |
| 每月 | 本月的那个日；本月已经过了就滚到下个月 |
| 每周 | 最近的一个相同星期几 |

**生日**是「每年重复」的特例：勾上「这是生日」后重复会自动切到每年，卡片文案变成「距离「小明」生日还有 N 天」，日期小字里额外显示「满 N 岁」（用你填的出生年份算，比如填 1999-05-20，2027 年那天就是满 28 岁）。当天则显示「「小明」生日快乐」。

设置界面的事件列表里也会标出这条是「每年」还是「生日」，不用点进去才知道。

## 农历日期

添加或编辑纪念日时，日期下面有 **公历 / 农历** 两个选项。选农历后，日期栏变成「正月～腊月」「初一～三十」两个下拉框，填的是农历月日，程序自动换算成对应的公历日期。

用农历的场景主要是农历生日、老人家的寿辰、祭日这类日子——比如填「八月十五」，摆件会每年自动找到当年中秋那天的公历日期，不用你一年年去查。

卡片日期小字会显示成 `2027-09-15 · 周三 · 农历八月十五`，一眼能看出这是按农历算的。

换算用的就是内置的 `lunar-javascript`，离线算，不需要联网。遇到小月没有三十日的情况，程序会跳过那一年，不会算错。

（农历日期暂时不显示「满几岁」，因为那需要额外的出生年份输入框；要算年龄可以用公历生日。）

## 中国法定节假日

摆件内置了 7 个法定节日，按「下一次」的日期自动排好，不需要手动添加：

| 节日 | 日期怎么来的 |
| --- | --- |
| 元旦 | 1 月 1 日 |
| 春节 | 农历正月初一 |
| 清明节 | 节气，每年 4 月 4–6 日之间 |
| 劳动节 | 5 月 1 日 |
| 端午节 | 农历五月初五 |
| 中秋节 | 农历八月十五 |
| 国庆节 | 10 月 1 日 |

### 日期从哪来

四个农历/节气节日（春节、清明、端午、中秋）的日期，直接取自 **香港天文台《公历与农历对照表》** 的官方数据：

- 数据源 `https://www.hko.gov.hk/tc/gts/time/calendar/text/files/T<年份>c.txt`，每年一份，公开下载
- 程序每年下载一次，从「正月」那天起算正月初一（春节），「五月」+4 天（端午），「八月」+14 天（中秋），节那一列直接给清明
- 表格本身按年发布，所以 2025–2028 的日期都能提前拿到，不用等

元旦 1/1、劳动节 5/1、国庆节 10/1 是固定公历日期，直接写死。

**断网兜底**：拿不到官方表时，自动退回内置的 `lunar-javascript`（`renderer/lib/lunar.js`，MIT 许可）本地换算。两套算法实测结果完全一致（2026–2028 逐项核对过），所以断网也不会算错，只是不如官方数据「有出处」。

在右键菜单的「切换纪念日」里，自定义纪念日和节假日会分两组列出（节假日那组带具体日期）；设置界面里可以整体关掉「显示中国法定节假日」。

### 联网同步放假安排

上面那张表只能算出**节日当天**，算不出「国庆连放 7 天」这种调休安排——那是国务院每年单独公布的，年年不同。

这里要说清楚：**国务院没有提供节假日 API**，每年只发一份文字公告（`gov.cn` 上的《关于X年部分节假日安排的通知》，正文就是「1月1日（周四）至3日（周六）放假调休，共3天」这种句子）。所以放假日程这一段，程序取的是公开接口做好的结构化数据，内容与公告逐条一致（内置的核对逻辑会拿它去比对节日日期）。

所以摆件会联网去拿这份安排：

- 启动 5 秒后自动同步一次，之后每 6 小时检查一次（同一年份 12 小时内只真正请求一次）
- 数据源是公开的节假日接口：主用 `holiday.ailcc.com`（每 24 小时跟随国务院公告更新，2027 年数据已可用），拿不到时自动换备份源 `timor.tech`，都只读、不需要账号
- 拿到后缓存在本地，断网也能继续用；没网或该年份还没公就保持原样，不会弹出错误
- 程序会把「节日当天」和抓到的公告区间逐条比对，设置页显示「已与公告核对」表示全部对得上；真有出入会提示「N 个日期待核实」
- 设置里「法定节假日」区块底部能看到同步状态，点「立即同步」可以手动拉一次（会顺带补上前一年）

拿到数据后，卡片日期小字会多一句，比如 `2026-10-01 · 周四 · 放假 7 天`；设置里的节日列表也会带上「7天」这样的标记。

**关于时效**：次年的放假安排通常要到当年 11–12 月才公布。目前能拿到 2025–2027 三年的完整安排（2027 年公告已发布），更远的年份公告一出，程序会自动补上，不用你管。

## 数据存在哪

```
C:\Users\<你的用户名>\AppData\Roaming\DaysMatterWidget\
├─ config.json          你的所有设置和纪念日
├─ holiday-cache.json   联网抓到的放假安排（删掉会重新拉）
└─ lunar-cache.json     香港天文台的节日日期（删掉会重新拉）
```

删掉 `config.json` 会恢复成默认的那一条示例（明年元旦）。

## 小提示

- 摆件是浮在其它窗口上层的，挡到东西可以拖开，或者右键取消「置顶显示」。
- 第一次启动会弹一次使用说明，之后不再弹。
- 改日期时请用 `YYYY-MM-DD` 格式（设置界面里的日期选择器会自动保证）。
- 生日这类每年重复的事件，日期栏填的是**原始日期**（比如出生那天），摆件上会自动换算成下一次。
