# lunar-javascript

本项目用 [lunar-javascript](https://github.com/6tail/lunar-javascript)（作者 6tail，MIT 许可）做农历换算。

`renderer/lib/lunar.js` 是从 npm 包 `lunar-javascript@1.7.8` 复制过来的，**不存入仓库**；克隆后执行：

```bash
npm run prepare-assets
```

`scripts/copy-lunar.js` 会从 `node_modules` 把它拷到这里。许可证见同目录 `lunar-LICENSE`。
